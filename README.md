# Pressroom

Pressroom is a desktop publishing app for Windows and Mac that opens, edits and prints Microsoft Publisher (.pub) files.

## Download

Get the newest installer from the [Releases page](https://github.com/alphanumeric-user/pressroom/releases/latest):

- **Windows:** `Pressroom-Setup-<version>.exe`
- **Mac (Apple silicon):** `Pressroom-<version>-Mac-AppleSilicon.pkg`
- **Mac (Intel):** `Pressroom-<version>-Mac-Intel.pkg`

Once installed, Pressroom updates itself automatically from this page.
